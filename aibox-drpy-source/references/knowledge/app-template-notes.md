# Aibox 模板源说明

目标站结构与当前 Aibox 模板吻合时，优先使用模板最小覆盖，不要一开始就手写完整规则。

## 使用条件

- 当前引擎模板表中真实存在候选模板。
- 展开继承后，分类、列表、详情、搜索和 lazy 的接口形态与目标站证据一致。
- 站点差异只涉及 `title`、`host`、路径或少数字段。

## 正确流程

1. 从 `third_party/aibox-engine` 动态列出模板，不维护手写模板名单。
2. 用真实首页、分类和详情响应比对候选模板。
3. 查看模板继承展开后的有效规则。
4. 只覆盖有证据的差异。
5. 运行 L1/L2/L3；模板匹配不能替代真实接口验证。

示例仅使用已经确认存在的模板名：

```javascript
var rule = {
  模板: 'mxpro',
  title: '站点名',
  host: 'https://example.com'
};
```

不要生成不存在的 `appapi`。无法确认模板时，先把站点判为 HTML、hybrid 或 API，再按“字符串 -> 混合 -> 局部 async -> 全 async”逐级实现。
